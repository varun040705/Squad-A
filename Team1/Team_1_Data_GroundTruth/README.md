# Team 1 — Data & Ground Truth: Combined Status (T1.1, T1.2, T1.3, T1.5)

Combined snapshot of everything built so far on the "Image → 2D/3D BIM Plan
Generator" project, Team 1 (Data & Ground Truth) stream.

## Folder guide

### `01_raw_images/cad/` — T1.1 (Image Sourcing & Categorization)
1,461 CAD-style floor plan images (1920x1080, CC BY 4.0, sourced from a
public Roboflow dataset). Renamed `FP_0001.jpg`–`FP_1461.jpg`.
**Not yet done:** scanned/photo/hand-drawn categories — this batch is CAD only.

### `03_metadata/dataset.csv` — T1.1
Per-image inventory: resolution, orientation, and automated
quality/difficulty/has_text/has_dimensions heuristics (percentile-relative to
this batch, not absolute — see caveats below). `number_of_rooms` is left
blank; it needs real visual/annotation work, not a guess.

### `04_annotations/ground_truth_module/` — T1.2 (Ground-Truth Annotation Pipeline)
The module (`builder.py`, `cleaner.py`, `room_extractor.py`,
`dimension_extractor.py`, `exporter.py`, `visualizer.py`) that turns raw
Roboflow annotations into a harmonized 5-class ground truth (wall, door,
window, room, dimension). Includes sample visual overlay proofs.

### `04_annotations/coco/{test,valid,train}/_ground_truth.coco.json` — T1.2 output
Generated by actually running the builder against the raw dataset.
Verified counts: **309,423 total annotations** across 1,461 images
(28,877 test / 65,783 valid / 214,763 train) — matches the module's own README.

### `04_annotations/aligned/` — T1.3 (Schema Alignment)
`schema_alignment_corrected.py` converts T1.2's ground truth into the shared
BIM Semantic Model schema (mm-scale walls with centerline/thickness/
connectivity, door/window-to-wall association, room polygons).
**Correction applied:** `WALL_TOPOLOGY_TOLERANCE_PX` was raised from 12px to
35px — the original value was measured against actual wall endpoint
distances and was catching only ~50% of genuine wall-to-wall junctions.
After the fix, wall connectivity rose from ~20% to ~91% across all splits.
The three `ground_truth_{split}.json` files here are the actual aligned
output, regenerated with the fix applied.

**Still an open caveat, not fixed:** `mm_per_pixel` scale is a low-confidence
(0.3) estimate derived from an assumed 12sqm average room size — there's no
real dimension-text OCR resolving true scale yet.

### `05_edge_cases/` — T1.5 (Edge-Case Set Curation)
`edge_cases_module/` (`metrics.py`, `selector.py`, `curator.py`) plus its
output: 93 images + `edge_case_manifest.csv` recording why each was flagged
(overall HARD difficulty, lowest sharpness, highest clutter, or most rotated).

**Important limitation:** since the source pool is 100% clean CAD renders,
these 93 are only *relatively* harder than their CAD peers — not genuinely
difficult in the real-world sense (perspective distortion, shadows, faded
scans, hand-drawn sketches, blurry photos). Real edge-case variety still
requires sourcing actual scanned/photographed/hand-drawn images.

### `02_curated_images/`, `06_splits/`
Placeholders — not yet populated. `02_curated_images/` was intended for a
cleaned/finalized subset distinct from raw; `06_splits/` for train/val/test
image-id lists once the dataset composition is finalized.

## Pipeline recap

```
T1.1 (raw images + dataset.csv)
        │
        ▼
T1.2 (ground_truth_module → _ground_truth.coco.json, 309,423 annotations)
        │
        ▼
T1.3 (schema_alignment_corrected.py → aligned/*.json, BIM Semantic Model)
        │
T1.5 (edge_cases_module → 05_edge_cases/, 93 CAD-relative hard cases)
```

## Known gaps carried forward
1. `scanned/`, `photo/`, `hand_drawn/` image categories — not sourced yet.
2. `number_of_rooms` in `dataset.csv` — not computed, needs manual/annotation work.
3. Real dimension-text OCR for true `mm_per_pixel` scale resolution.
4. Genuine (non-CAD) edge cases once real scanned/photo/hand-drawn images exist.
